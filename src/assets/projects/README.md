# Prints dos projetos

Coloque aqui um print por projeto, com o nome igual ao `id` em `src/data/projects.ts`:

- `priscilaneo.webp`
- `mrfTrocas.webp`
- `minhaEtiqueta.webp`
- `lightsOut.webp`
- `estoque.webp`

Formatos aceitos: `.webp`, `.avif`, `.png`, `.jpg`. Quando o arquivo existe, ele substitui a ilustração do card automaticamente.

Dicas:

- Use um print de página inteira (ex.: 1440 px de largura). No hover, a imagem rola dentro da janela do card até o fim.
- Prefira `.webp` com qualidade em torno de 80 para manter o arquivo leve.
